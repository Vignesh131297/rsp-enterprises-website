# RSP Enterprises – website

Static website for RSP Enterprises (excavation, shoring, rock breaking, demolition and building & land development, Bangalore – Hosur, since 2000). Plain HTML, CSS and JavaScript – no build step. Hosted on GitHub Pages from the `main` branch.

## Pages

| File | Page |
|---|---|
| `index.html` | Home – rock-breaking demo and Basement Planner |
| `about.html` | About, clients, team and safety |
| `services.html` | Services and the "Available this week" fleet board |
| `projects.html` | Projects, rock-to-ready slider and project map |
| `contact.html` | Enquiry form (opens WhatsApp) and office details |

## Common updates

- **Fleet availability:** edit `AVAILABLE_THIS_WEEK` and `UPDATED_ON` at the top of `assets/js/services.js`. Use `null` to show "Ask for this week".
- **Projects:** edit the `projects` list at the top of `assets/js/projects.js`. Leave `img` empty to show the "Site photos coming soon" tile.
- **Images:** live in `assets/img/`.

After editing, commit and push to `main`; GitHub Pages updates the live site within a minute or two.
